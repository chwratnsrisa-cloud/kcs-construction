ตั้งค่าการเผยแพร่ (ทำครั้งเดียว)

ตั้งครั้งเดียว หลังจากนั้นกดปุ่มเดียวเว็บอัปเดตเอง ข้อมูลนี้เก็บในเครื่องนี้เท่านั้น ไม่ถูกใส่ลงไฟล์เว็บ

วิธีเอาค่ามาใส่ (ทำครั้งเดียว)
1
สมัคร GitHub

ไปที่ github.com สมัครฟรี ชื่อผู้ใช้ที่ตั้งคือค่าในช่อง “ชื่อผู้ใช้ GitHub”

2
สร้างที่เก็บไฟล์

github.com/new → ตั้งชื่อ kcs → เลือก Public → ติ๊ก Add a README → Create

3
อัปไฟล์เว็บขึ้นครั้งแรก

ในหน้า repo กด Add file → Upload files → เลือกไฟล์ index.html → Commit

4
สร้างโทเคน

github.com/settings/personal-access-tokens → Generate new token → เลือก repo ของคุณ → ตั้ง Contents เป็น Read and write → Generate แล้วคัดลอกมาวางในช่องโทเคน

5
เปิดเว็บให้คนเข้าดู

ใน repo → Settings → Pages → Branch เลือก main → Save (หรือผูก repo นี้กับ Netlify เดิมเพื่อใช้ลิงก์เดิมต่อ)

โทเคนเก็บอยู่ในเครื่องนี้เท่านั้น ไม่ถูกใส่ลงไฟล์เว็บและไม่อยู่ในไฟล์สำรอง ถ้าเปลี่ยนเครื่องต้องใส่ใหม่

วิธีขึ้นเว็บ (ของคุณเอง)
ขั้นตอนหลัก
1
แก้ไขเนื้อหาในหน้านี้

ใส่แบบบ้าน รูป ผลงาน รีวิว ทีมช่าง ราคาต่อตารางเมตร ข้อมูลจะเก็บในเครื่องนี้ทันที

2
กด “สร้างไฟล์เว็บเวอร์ชันใหม่”

จะได้ไฟล์ index.html ไฟล์เดียว ข้างในมีทั้งเว็บและรูปทั้งหมดแล้ว

3
อัปไฟล์ขึ้นโฮสต์

ลากไฟล์ไปวางที่ app.netlify.com/drop หรือ Cloudflare Pages จะได้ลิงก์ของคุณทันที ครั้งต่อไปลากทับไฟล์เดิม

4
ตั้งชื่อลิงก์เป็นชื่อร้าน

สมัครฟรีกับโฮสต์ แล้วเปลี่ยนชื่อเป็น kcs-changkosang หรือจะซื้อโดเมนของตัวเองมาผูกก็ได้

สิ่งที่ควรรู้

• ไฟล์เว็บที่สร้างมีเฉพาะข้อมูลที่ลูกค้าเห็น — เอกสาร ใบเสนอราคา และข้อมูลลูกค้า ไม่ถูกใส่ลงไปในไฟล์
• เอกสารทั้งหมดเก็บอยู่ในเครื่องนี้เท่านั้น ควรกด “สำรองข้อมูล” เก็บไฟล์ไว้เป็นระยะ
• รหัสเข้าโหมดแก้ไขกันความสับสนของลูกค้า ไม่ใช่ระบบความปลอดภัย คนที่เปิดดูโค้ดหน้าเว็บจะเห็นรหัสได้ แต่แก้ได้แค่ในเครื่องของตัวเอง ไม่กระทบเว็บจริง
• แก้ไขจากเครื่องไหน ข้อมูลอยู่ในเครื่องนั้น ถ้าจะย้ายเครื่อง ให้สำรองข้อมูลแล้วกู้คืนในเครื่องใหม่
